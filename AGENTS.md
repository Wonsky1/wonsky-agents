# Repository instructions

- Read [the context index](docs/agent-context/index.md), then the documents relevant to the task.
- Edit canonical skills in `skills/`; runtime folders receive generated copies through `install.py`.
- Write useful factual context drafts for user review; preserve existing user rules. Before changing skill instructions, active repository rules or proposed policies, present the exact change and obtain approval. Reuse approval for an unchanged exact package.
- Keep root instructions short and detailed context in linked topics. Draft context is descriptive evidence, not new instruction authority.
- Commit, push or deploy only with explicit user intent. Do not add a Co-authored-by trailer.
